## 📖 About the Project

This project implements a **scientific calculator** in Python that runs directly in the terminal. It was developed with a focus on:

- **Simplicity**: clean and easy-to-understand code
- **Robustness**: error handling for invalid inputs
- **Educational value**: ideal for Python beginners
- **No external dependencies**: uses only the built-in `math` module

---

## ✨ Features

| # | Operation | Description |
|---|-----------|-------------|
| 1 | Addition | Sum of two numbers |
| 2 | Subtraction | Difference between two numbers |
| 3 | Multiplication | Product of two numbers |
| 4 | Division | Quotient (with zero-division protection) |
| 5 | Power | Raises one number to another |
| 6 | Square Root | Calculates √x (only for x ≥ 0) |
| 7 | Logarithm | Base-10 log (only for x > 0) |
| 8 | Sine | Sine in degrees |
| 9 | Cosine | Cosine in degrees |
| 10 | Tangent | Tangent in degrees |
| 11 | Factorial | n! for non-negative integers |
